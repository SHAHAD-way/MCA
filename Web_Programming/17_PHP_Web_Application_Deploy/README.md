# Program 17 – Develop and deploy a PHP web application

1. Copy this folder to the web server document root (for XAMPP: `htdocs`).
2. Start Apache from the XAMPP control panel.
3. Browse to `http://localhost/17_PHP_Web_Application_Deploy/`.
4. Enter a name and submit the form to verify PHP processing.

For hosting, upload the files to a PHP-enabled hosting account and configure the
document root to this folder. Test the deployed URL over HTTPS. This exercise is
a small demonstration application, not a production user-account system.
